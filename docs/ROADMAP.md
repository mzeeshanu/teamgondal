# Roadmap

## Phase 1: Launch (now)
- [x] Website with home, events, drivers, join and about pages
- [x] API with events and drivers, Postgres, health checks, tests
- [x] CI on GitHub Actions, Railway config as code
- [ ] Deploy to Railway and connect teamgondal.com
- [ ] Discord invite link on the Join page

## Phase 2: Members
- [ ] Sign in with Discord (OAuth) on the web app
- [ ] Driver profiles created on first sign in, linked by Discord id
- [ ] Roles from Discord (admin, steward, driver) replace the admin key
- [ ] Admin pages to create and edit events
- [ ] Event sign ups and grid limits

## Phase 3: Racing data
- [ ] Ingest race results from our AssettoServer (results JSON or a server plugin)
- [ ] Results pages per event, lap times and fastest laps
- [ ] League championships with points and standings
- [ ] Live server status (players online, track, session)

## Phase 4: Community
- [ ] Discord bot: event reminders, results posts, role sync
- [ ] Driver stats and history
- [ ] Merch store for team wear
- [ ] Media: race highlights from the techyGondal channel
